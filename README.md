# 🍰 Lāčuka Gardumi — Mājaslapa

Oficiālā mājaslapa mājražotāja konditorejai **"Lāčuka Gardumi"** Mārupē.

🌐 **Tiešsaistes adrese:** [lacukagardumi.lv](https://lacukagardumi.lv)

---

## 📖 Par projektu

"Lāčuka Gardumi" ir PVD reģistrēta mājražotājas Sintijas konditoreja Mārupē, kas piedāvā individuāli gatavotas kūkas, bento kūciņas, ciparkūkas, cepumus un kēksiņus svētkiem un īpašiem mirkļiem.

Mājaslapa veidota kā ātra, eleganta un mobilo ierīču draudzīga vizītkarte ar pilnu produktu piedāvājumu, cenām, galeriju un pasūtīšanas instrukciju.

---

## 🛠 Tehniskā uzbūve

* **Hostings:** GitHub Pages (izvietots no `main` zara)
* **Domēns:** Pielāgots domēns `lacukagardumi.lv` (norādīts failā `CNAME`)
* **Tehnoloģijas:** Semantisks HTML5, pielāgots CSS un viegls Vanilla JavaScript
* **SEO & Sociālie tīkli:**
  * Pilns **Open Graph** un **Twitter Card** atbalsts ar optimizētu koplietošanas attēlu (`assets/og-image.jpg` 1200×630 px)
  * Strukturētie dati meklētājiem: **Schema.org (JSON-LD)** `Bakery` / `LocalBusiness`
  * Vietnes karte: `sitemap.xml` ar lapas un produktu bilžu indeksāciju
  * Meklētāju roboti: `robots.txt`
  * Verificēts **Google Search Console** meklēšanas indeksācijai

## 🚀 Kā veikt izmaiņas un atjaunināt mājaslapu

Pateicoties GitHub Pages, jebkuras izmaiņas, kas tiek iesniegtas `main` zarā, automātiski atjaunojas mājaslapā dažu minūšu laikā:

1. Veic nepieciešamos labojumus failos (piemēram, [index.html](index.html)).
2. Sagatavo un nosūti izmaiņas uz GitHub:
   ```bash
   git add .
   git commit -m "Atjaunota informācija"
   git push origin main
   ```
3. GitHub Pages automātiski pārpublicēs jauno versiju vietnē [lacukagardumi.lv](https://lacukagardumi.lv).
